# Paper reference

[Enhancing Bilinear Subspace Learning by Element Rearrangement](https://www.ee.columbia.edu/ln/dvmm/publications/09/xu_ebsl.pdf), Xu et al., IEEE TPAMI 31(10), 1913-1920, 2009.

`citation.bib` contains the citation. `paper_table1.json` transcribes the published comparison table and labels those values as literature results. The original PDF and extracted text are not redistributed here. `scripts/download_data.py` retrieves and verifies a local copy when needed.
